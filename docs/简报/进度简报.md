## 术语表（本项目口径，勿用通用定义曲解）

| 术语 | 定义 |
|---|---|
| **连续口径** | 一组的次数 = 不间断连续完成的次数；顶点静态维持/rest-pause 凑的不算（10-27 起执行） |
| **处方四条件** | 加重的全部条件：①组数满区间上限 ②末组 RIR 1~2 ③姿势不变形 ④**连续 2 次训练达标** |
| **单边口径** | `ppl_pull_barbell_curl` 重量记单手负荷（7.5=每手=EZ 杆总 15kg），其他动作全是总重；容量对比前弯举 ×2 |
| **晨脉规则** | 基线 64~68；≥72 当天不追加负荷、加重名额顺延；≥75 触发四查（负荷/睡眠/蛋白/压力） |
| **限位/闸门** | 限位=任一不过就停（硬边界）；闸门=全过才放行（准入条件）。定义见验收标准文档 |
