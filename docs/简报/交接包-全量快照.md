- **升版规则**：目标值或截止日变 → 升 G（连带重算链条）；只改排法/顺序/剂量 → 只升 P，G 不动。计划「依据版本」必须等于目标档案当前版本。
- **再特化协议（三级）**：L1 微调（仅数字，P1.1→P1.1.1）/ L2 特化（结构，G 不动）/ L3 重排（P2.0+G2.0 全链重算）。L1/L2 可周期中执行；L1 每周最多一次，L2 必须留变更记录。

  - **S2 深蹲容量环（主环）**：60×4×12，末组冲封顶 15 次；5 个蹲日判定，顺利 12-05 完成、不顺 12-24。
  - **S3 深蹲力量**：80×6（力量日内容即 S3 的持续验证，不单独开环）。
  - **B1 平板技术块**：肩胛控制重建 6 周至 12-06，现 1/6 周；剂量三层（每日 2 分钟微剂量 + 拉日末尾 12 分钟短版 + 力量日 18 分钟正课，共 8 次暴露）。

### 3.3 M1 当前位置

- M1 = **16 场**排期，**单位是「场」不是天**（1 微周期 = 4 场）。频率波动大，按场次推进才稳。
- **微周期顺序：蹲 → 拉 → 力量 → 推**（P1.1 修正）。理由：原顺序会把蹲容量（60×48）和蹲力量（80×18）排到 48h 内，是最贵的相邻对；新顺序只留两个便宜的相邻（硬拉 35kg↔深蹲 80、平板↔平板——后者是技术块刻意为之的频率）。缓解项：拉日山羊挺身在「下一场是力量日」时减为 2×12。
- **第 1 场（蹲日 60×4×12 末组冲封顶 15）尚未执行**。第 1 场末组次数直接决定 S2 路径：15 次 → 跳过确认场 → 12-24 提前到 12-13。
- 新增 5 个记录字段（`last_set_reps` / `rir` / `form_break` / `warmup_done` / `lumbar_status`）目前 **0 个在用**——M1 的瓶颈在记录不在训练。

### 3.4 频率及格线与日期投影

- **D0（最低纪律）**：7 天滚动 ≥3 场；学期内允许连续 2 周降至 2 场；寒暑假 ≥3.5。未达 D0 时 D1 之后全部顺延，不判失败。

1. **处方冻结**：现行处方 = 《codex-list/推拉蹲训练体系-做组处方-2026-10-16重算版.md》，用户明确「持续用直到自己觉得需要改」，不要建议改处方结构。
2. **执行层文件已换代**：现行执行入口 = `docs/微周期1执行卡-M1-1-2026-10-29.md`（逐场给出动作表/容量账/唯一产出/判定/消息模板）；~~《codex-list/拉日执行单-2026-10-19起.md》~~ 已被 M1 执行卡取代。
3. **弯举重量口径**：`ppl_pull_barbell_curl` 的 weight_kg 是**单边负荷**（7.5 = 每手 7.5 = EZ 杆总重 15kg），其他动作全是总重。拉日容量对比前须对弯举 ×2 修正（否则低估约 6.5%）。用户 EZ 杆 1RM ≈ 26.6kg 总重。
4. **次数口径**：一律「连续次数」，顶点静态维持/rest-pause 凑的次数不算（10-27 起执行）。外部 AI 分析容量时先确认口径。
5. **晨脉规则**：基线 64~68 bpm。≥72 当天不追加负荷；≥75 触发四查（睡眠 / 酒精烟 / 前日负荷 / 疾病征兆与压力）。单点越线不慌，连续两天 ≥75 或有症状才升级。
6. **加重条件（处方四条）**：① 全部组数满区间上限 ② 最后一组剩 1~2 次余力 ③ 姿势不变形 ④ 连续 2 次训练达标。晨脉 ≥72 的当天不执行加重（名额顺延）。
7. **记录归时**：底座习惯时间戳默认归属前一天 20:00（早上录昨天）；补录用 `?day=YYYY-MM-DD`。
8. **用户是男性**，80kg / 20 岁 / 训练 2 年；蛋白目标 ≥130g/天（现实约 60~80g）。营养/补剂建议按男性口径（不无指征补铁）。
9. **大目标唯一口径**：2027-12-31 深蹲 120×1 + 平板 80×8（加速线 105×3 可选）。目标值以目标档案 G1.0 为准；验收标准与处方数值以节点表 v3.3 为准；执行卡与计划冲突时计划赢。
10. **硬拉特殊轨道（最重要的一条）**：08-07 PR 梯最高 **130×3（e1RM 143）**，但日常只用 **35×4×12（腰部耐受档）**——用户原话「做太重能起来但对腰部负担大」。硬拉不设 e1RM 目标（143 是单次标定，「爬回 143」不是进步）；加重只看 **G7 门控**：连续 3 场 `lumbar_status`=`none` 才 +5kg（本周期封顶 45kg 容量档 / 力量日 45×3×6 派生值）；连续 2 场 `pain` → 回退 5kg 停 2 周。**任何「硬拉应该上 60/80」的建议都是错的。**
11. **微周期顺序红线**：蹲→拉→力量→推，不许自行换序；换序需走再特化协议（L2）。周期单位是场（4 场 = 1 微周期）。
12. **深蹲末组封顶 15 次**：15 → 周期吨位 17,760（+4.6%，L4 内）；18 → 17,940（+5.7%，破 L4）。末组满了加重的是重量不是次数。
13. **RIR 定义** = 末组实际次数 − 处方次数（这是 AMRAP 与规则 2② 不冲突的唯一桥，不使用其他 RIR 口径）。
14. **e1RM 只在次数差 ≤2 次的档位间可比**（12 次外推 +40%、6 次 +20%、1 次 +3%）——跨大次数档比较 e1RM 会得到虚高结论（硬拉 114→49 的旧「悬账」一半由此而来）。
15. **没去必须记**：`ppl_*` 里「没去」和「没记」无法区分；缺席训练要发「没去 MM-DD」，否则频率统计会虚低。

## 六、已知数据陷阱（手工段，7 条）

1. **8 月峰值真实值**（10-29 实查发现）：节点表 D0 行把 8 月峰值三个动作全写成「80×8（e1RM 101）」，是复制粘贴错误。**真实为：硬拉 130×3（e1RM 143）/ 深蹲 110×4（124.7）/ 平板 75×4（85）**。据此回收率：深蹲 96/124.7 = **77%**、平板 67/85 = **79%**；深蹲 120×1 = 峰值的 99%（「恢复」而非「突破」）。⚠️ 内部文档尚未修正（已列入 00-总索引 §五 悬账，待下次统一修节点表 D0 行/回收率表/目标档案口径注解/调研 §6.4 概率）。**本交接包以 §2.4 实查数据为准。**
2. **e1RM 跨次数档不可比**：见红线 14。外部 AI 若直接拿 35×12 的 e1RM 49 去和 90×8 的 114 比，会得出「掉了一半力量」的错误结论。
3. **PR 梯里的标定值不是日常训练重量**：同一动作同一个人，130×3（测试日顶组）与 35×12（日常容量组）并存是常态，不是矛盾、不是换器械、不是换动作。
4. **488 组零崩点**：历史 488 组没有一次 `form_break`——处方次数总是被当天天花板用完，末组从不掉次数。所以 RIR 数据缺失时 AMRAP（规则 8）是 B1 能否验收的前提，不能只看表面次数达标。
5. **「没去」和「没记」在库里一样**：见红线 15。
6. **5 个新字段 0 个在用**：`last_set_reps` / `rir` / `form_break` / `warmup_done` / `lumbar_status` 已定义未使用，所有环判定都可能卡在缺数据。外部 AI 给建议时先问「数据够不够判」，不要凭空推加重。
7. **弯举单边口径**：见红线 3，容量对比前必须 ×2。
