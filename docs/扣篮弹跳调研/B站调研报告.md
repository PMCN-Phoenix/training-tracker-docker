## 〇、结论速览

1. **B 站主流共识与学术文献一致**：深蹲 1.5×BW 是"力量是否还是瓶颈"的关键阈值；超过 2×BW 后，继续堆深蹲重量对弹跳的边际收益下降，瓶颈转移到 RFD（发力率）和神经肌肉协调。

3. **高翻/力量翻在 B 站被推荐为"不练就亏"的动作**，但教学视频普遍偏短（<2 分钟），技术细节不足，需要配合 YouTube/学术资料补。
4. **反面声音**：有 UP 主标题直接写"纵跳摸高训练不要再练深蹲了"——但内容并非否定深蹲，而是批评"只练深蹲不练跳跃专项"。

## 三、B 站内容的局限与缺失

1. **量化数据少**：B 站视频普遍讲"1.5 倍体重"、"2 倍体重"，但很少给出"蹲到 X kg 对应跳 Y cm"的回归数据。这部分必须靠学术文献补。
2. **高翻教学深度不足**：最长的高翻教学视频只有 97s，无法覆盖悬垂翻、midthigh pull、hang high pull 等衍生动作的剂量。
3. **周期化模板多为 8 周短周期**：B 站 UP 主的 8 周计划适合"起步"，但用户目标（100cm 助跑 VJ）需要 21–29 个月的长期规划，B 站内容覆盖不到。
4. **2 个视频无 AI 字幕**（BV1MP4y1F7Zh、BV1nm4y177Sy），未抓到内容，仅参考标题。按 SOP 要求如实标注，不编造。

## 四、对用户的可执行建议（B 站视角）

1. **当前 1.20×BW → 优先堆深蹲到 1.5×BW（120kg 1RM）**，B 站 UP 主和学术文献一致认为这是"力量是否还是瓶颈"的分水岭。
2. **8 周为一个 mesocycle**，每 8 周自测一次 CMJ 和深蹲 1RM，观察是否同步提升。
3. **高翻从 hang high pull 开始**（技术门槛低），不要直接学 full power clean。
4. **不要相信"4 周扣篮速成"**，B 站头部 UP 主自己都在批判这种营销。
