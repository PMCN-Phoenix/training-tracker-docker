# 深蹲重量目标 + 力量转爆发力（扣篮/垂直弹跳）综合调研

> 调研日期：2026-10-14
> 用户锚点：181cm / 80kg，站立摸高 230cm，目标摸高 330cm（需垂直起跳 ≈100cm 助跑 VJ）
> 当前深蹲 PR：80kg×6（Epley/Brzycki 公式反推 1RM ≈ **96kg**，BW 比 ≈ **1.20×**）

---

## 〇、一句话结论

**从当前 1.20×BW 到能扣篮（助跑 VJ 100cm），深蹲 1RM 目标是 160kg（2.00×BW），总耗时预计 21–29 个月；前 8 个月优先把深蹲从 96kg 堆到 120kg（1.50×BW）过 depth jump 准入线，之后再用 block periodization 把力量转化为弹跳。**

## 二、扣篮所需深蹲体重比的定量结论

### 2.1 核心数据

- **深蹲 1RM 与纵跳高度的相关性 r = 0.17–0.91**，高度依赖运动项目：
  - 精英篮球（前蹲）：r = **0.89–0.91**（Warneke 2023, n=42）
  - 精英足球（背蹲）：r = **0.71–0.78**（Wisloff 2004）
  - 力量举运动员：r = **0.34–0.39**（且 2.57×BW 硬拉也跳不高）
- **行业基准（NSCA / PoinT Go 2026）**：
  - Elite：背蹲 **>2.0×BW**
  - Good：1.6–2.0×BW
  - Developing：1.2–1.6×BW
- **492 青年足球大样本（PMC9140541）**：
  - 1.0–1.5×BW 组：平均 CMJ 38.7cm
  - 1.5–2.0×BW 组：平均 CMJ 44.0cm
  - >2.0×BW 组：无样本（说明该群体没人到这个区间）

### 2.2 反面证据（必须知道）

1. **力量举悖论**：力量举运动员平均硬拉 2.57×BW，纵跳高度与 1.3×BW 足球队员**无显著差异**（PMC10825955, 2024）。
2. **8 周 RCT（PMC9499257）**：纯 weightlifting derivatives（高翻/pull）组对纵跳高度**无显著提升**；plyometric 组 SJ 高度 +7.8%。
3. **Duke D1 男篮研究（PLoS ONE 2025）**：膝伸肌峰力矩与 VJ 高度**无显著相关**，唯一预测因子是"到达峰力矩时间"（RFD），仅解释 23% 方差。
4. **大重量深蹲急性抑制弹跳**：男性 1RM 越高，70% 1RM 深蹲后 CMJ 下降越多（r = -0.54，PMC3761744）。

**结论**：深蹲体重比是必要条件不是充分条件。1.5×BW 以下力量是瓶颈；1.5–2.0×BW 是转化黄金区间；>2.0×BW 后继续堆深蹲对弹跳边际收益下降，瓶颈转移到 RFD / SSC / 神经肌肉协调。

## 三、分阶段目标线

| 阶段 | 深蹲 1RM | BW 比 | 预期 CMJ | 预期助跑 VJ | 预计耗时 | 训练 focus |
|---|---|---|---|---|---|---|
| **当前** | 96 kg | 1.20× | ~45–55 cm（估） | ~55–65 cm | — | — |
| **阶段 1：力量打底** | 110 kg | 1.38× | 55–60 cm | 65–70 cm | **3–4 个月** | 背蹲 5×5 渐进 + 低强度 plyo（CMJ/box jump）每周 1–2 次 |
| **阶段 2：过 depth jump 准入线** | **120 kg** | **1.50×** | 62–68 cm | 72–78 cm | **再 4–5 个月** | 开始 depth jump（30–45cm 箱）+ hang high pull |
| **阶段 3：专项转化** | 140 kg | 1.75× | 70–75 cm | 82–90 cm | **再 6–8 个月** | block periodization：最大力量块 → 转化块 → 专项峰值块 |
| **阶段 4：扣篮线** | **160 kg** | **2.00×** | **80–85 cm** | **95–105 cm** | **再 8–12 个月** | 助跑技术、落地力学、体重控制 <10% body fat |

**总耗时：21–29 个月**（训练年龄中等，非新手红利期）。

**关键门槛解释**：
- **1.50×BW = 120kg**：NSCA / Chu & Myer 共识的 depth jump 准入线。低于此线做 depth jump 伤膝风险 > 收益。
- **1.75×BW = 140kg**：进入 Good 区间上半段，开始做力量→爆发力转化 block。
- **2.00×BW = 160kg**：Elite 门槛，配合跳跃专项训练可达到助跑 100cm。

## 四、力量→爆发力转化训练方案

### 4.1 什么时候开始转专项？

**准入门槛**：背蹲 1RM 达到 **1.50×BW（120kg）** 后再上 depth jump。当前 1.20×BW → 先继续堆最大力量 4–5 个月。

### 4.2 动作选择与剂量

| 类别 | 动作 | 剂量 | 频率 | 阶段 |
|---|---|---|---|---|
| **最大力量** | 背蹲 | 5×5 → 5×3 → 3×2（80–90% 1RM） | 2×/周 | 阶段 1–3 |
| **辅助力量** | Front squat / RDL / Bulgarian split squat | 3×8–10 | 1–2×/周 | 全程 |
| **力量举衍生（RFD）** | Hang high pull（悬垂高拉） | 4×5，60–75% hang clean 1RM | 1×/周 | 阶段 2 起 |
| **力量举衍生（RFD）** | Midthigh power clean（技术 OK 后） | 4×3，70–80% 1RM | 1×/周 | 阶段 3 |
| **低强度 plyo** | CMJ、box jump、ankle hop | 3–4×5–8 | 2×/周 | 全程 |
| **高强度 plyo** | Depth jump（30→45cm 箱） | 3–4×5，ground contact <0.3s | 1–2×/周 | 阶段 2 起（1.5×BW 后） |
| **专项** | Approach jump practice（助跑摸高） | 5×3 max effort | 1×/周 | 阶段 3 起 |

### 4.3 周结构（贴进现有推拉蹲三日框架）

**阶段 1（1.20→1.38×BW，力量打底）**：

| 日 | 内容 |
|---|---|
| 周一（腿前侧 + 力量） | 背蹲 5×5 + front squat 3×8 + leg curl 3×10 + CMJ 3×5（session 最前面，CNS 新鲜时） |
| 周二（推） | 现有的推日，不变 |
| 周三（拉） | 现有的拉日，不变 |
| 周四（腿后侧 + 爆发） | RDL 4×6 + Bulgarian split squat 3×8 + ankle hop 3×10 + box jump 3×5 |
| 周五（休/有氧） | 慢走或自行车 30 分钟 |
| 周六（全身补充） | 核心 + 踝背屈活动度 |
| 周日（休） | — |

**阶段 2（1.38→1.50×BW，过 depth jump 线）**：
- 周一：背蹲 5×3（85–90%）+ hang high pull 4×5 + depth jump 3×5（**放在最前面**）
- 周四：front squat 4×5 + hurdle hop 3×8 + approach jump practice 5×3

**阶段 3（1.50→1.75×BW，专项转化 block）**：
- 每 4–6 周一个 block：
  - Block A（最大力量 4 周）：背蹲 85–95%，plyo 维持量（每周 60 contacts）
  - Block B（转化 4 周）：jump squat 30–45% 1RM + depth jump 45cm，背蹲降到 3×3 @ 80%（维持）
  - Block C（专项峰值 2 周）：approach jump practice + band-assisted jump，量减 50%，强度 max

### 4.4 疲劳管理与排课

- **Plyometric 必须放在力量训练 session 最前面**（CNS 新鲜时），大重量深蹲放后面（oxCbu1A4WtQ / PMC3761744）
- **组间休息**：plyo 2–3 分钟，大重量深蹲 3–5 分钟
- **大重量深蹲日与跳跃日间隔 ≥ 24 小时**（急性疲劳抑制弹跳）
- **每周 total foot contacts**：
  - 阶段 1：60–80（低强度）
  - 阶段 2：100–120
  - 阶段 3：120–150
- **48 小时规则**：plyo 日之间至少隔 48 小时（肌腱胶原合成峰值在 24–48h）

### 4.5 落地力学与伤膝风险

- Depth jump 箱高从 30cm 开始，能 ground contact <0.3s 且 landing 安静时再升到 45cm
- Landing 时膝对准脚尖，不要内扣；保持 quarter squat 幅度（不要蹲到平行）
- 膝痛出现：降 volume 50%，休息 48–72h；持续疼痛 → 停 depth jump，回退到 box jump
- 体重控制 <10% body fat（Isaiah Rivera 经验法则，减少膝关节 GRF）

## 五、反面意见单独成节

1. **"深蹲越重跳得越高"是错的**：力量举 2.57×BW 也跳不高（PMC10825955）。力量是必要不充分条件。
2. **"高翻万能"被高估**：MacKenzie 2014 显示 power clean 运动学与 CMJ 差异大；8 周 RCT（PMC9499257）显示纯 weightlifting derivatives 对纵跳高度无显著提升。高翻的价值是训练 RFD，不是动作相似。
3. **"付费 program 一定涨"是错的**：Jump Science 2.0 评测者 10 周后 standing VJ 反而下降（5W3lKB59YUI）。个体差异大。
4. **"每天都跳"是错的**：肌腱需要 48h 恢复；每周 4+ 次 plyo 边际收益消失，伤腱风险上升（Ramírez-Campillo 2020）。
5. **"大重量深蹲后立刻测弹跳"会误导**：急性疲劳抑制弹跳（PMC3761744），测试 CMJ 应安排在新鲜日。
6. **100cm 助跑 VJ 是 NBA 边缘水平**：不是 1 年能完成的目标。用户需要 21–29 个月，且不保证达到（遗传、骨结构、训练年龄都是变量）。

## 六、待拍板项

在开始执行前，需要用户决策：

1. **是否接受 21–29 个月的时间线？** 如果希望更快，需要降低目标（例如先摸到 320cm 而非 330cm），或接受更高的伤膝风险。
2. **当前 CMJ / 助跑 VJ 实测值是多少？** 报告里按 45–55cm 估算，如果实测差距大（例如已经 60cm+），目标线要重算。
3. **是否愿意学 hang high pull / midthigh pull？** 如果不愿意碰奥林匹克举衍生动作，转化 block 改用 jump squat + depth jump 组合，效果略差但可接受。
4. **体重是否愿意降到 <10% body fat？** 当前 80kg，如果体脂率 >15%，减重 3–5kg 对 VJ 的提升可能比多蹲 10kg 更明显。
5. **现有推拉蹲三日框架的具体动作和组数？** 报告给出的周结构是通用模板，需要贴进用户现有框架时可能要微调。
6. **是否愿意每 4–6 周换一个动作（front squat → trap-bar deadlift → step-up）？** Isaiah Rivera 经验：不换动作会 plateau。
