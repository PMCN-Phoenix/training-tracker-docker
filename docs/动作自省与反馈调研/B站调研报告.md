## 2. 按子问题组织的关键发现

### 2.1 没有分数时的进步代理指标

**核心结论：B站健身圈用 RPE/RIR + 动作质量 + 募集感觉三个维度替代"重量分数"。**

**凯圣王 BV15Y4y1u71f（RM/RPE 体系）**：
- `00:11-00:21`："我们上来是要守着 RM 去做、守着 RPE 去做，而不是守着公斤去做。这个是很多人在健身房为什么好长时间没有进步，而且容易受伤，最经常犯的错误。"
- `03:10-03:28`：RPE 定义——"10 RPE 就是我做完最后一个的时候，已经拼尽全力在做最后一个了，我不可能再多做，哪怕半个都做不了。"
- `03:45-03:49`：状态差异——"我头天睡好了，心情很好，精神很足"，所以 RPE 是**每天浮动的**，不是固定的。

**自然健身王正浩 BV1ByGL6rEX8（动作质量优先）**：
- `00:28-00:34`："次数的前提是重量，重量的前提是动作完成质量。你的动作框架动作目的才是第一位的。"
- `01:35-01:43`："宁轻勿假。在动作质量保障的前提之下……我也是能增加一些重量，我就会增加一些重量。"
- `01:46-01:52`："但状态不是一成不变的……下滑了以后，我也会根据状态去减轻一些重量。"——**重量浮动是正常的，关键是动作质量不浮动**。

**凯圣王 BV1sh411e7i6（专门性是"风向标"）**：
- `05:05-05:24`："你的专门性可能就要变成什么动作的标准……你要学会最基础的卧推是什么样的动作、硬拉什么样的动作、深蹲什么样的动作。再往后可能你的专门性放到肌肉的募集感觉。"
- **关键洞察**：进步的"代理指标"随阶段变化——新手期看动作标准度，中期看募集感觉，后期看重量。**不是所有阶段都用同一个指标。**

- "测量的数据点越小" = 不是"今天推了 80kg"，是"今天底部停 1 秒不松的次数从 0 变成 2"

### 2.6 动作熟练度阶段标志

**BV1sh411e7i6 给出了 B站版本的阶段划分**（虽然没用 Fitts-Posner 术语）：
- `05:05-05:24`：第一阶段 = **动作标准**（"卧推是什么样的动作、硬拉什么样、深蹲什么样"）
- `05:24-06:43`：第二阶段 = **募集感觉**（"你的专门性放到肌肉的募集感觉"）
- 评论区 241 赞补充：第三阶段 = **重量渐进**（"动作质量>耐力>重量>代谢压力"）

**这和 Fitts-Posner 三阶段对应**：
- 认知期 = 动作标准（新手学"动作长什么样"）
- 联结期 = 募集感觉（中级学"怎么控制动作"）
- 自动化期 = 重量渐进（高级在疲劳下仍能保持动作 + 加重）

## 3. 反面意见 / 失败案例（B站语料）

### 3.1 "动作标准本身是伪命题"（BV1ByGL6rEX8 评论，8 赞）

> kickerass："健身这个东西各个博主自己有自己的总结，但他们都没有进行普世验证，所以都是见仁见智……所谓的动作标准本身就是个伪命题，而且每个博主的标准都各有差异，甚至每个人身体都各有差异。"

**含义**：不要迷信"教科书动作"——每个人的骨骼结构不同，卧推握距、深蹲站距都应该个体化。录像对照的目的是发现**自己的**错误模式，不是复制"标准动作"。

### 3.2 "轻重量找发力感"是割韭菜？（BV1Qo4y1Z7jQ）

- UP 主核心论点：轻重量找发力感在大重量下不迁移
- **评论区 33 赞调和观点**："轻重量目的不是找所谓的发力感，而是把动作打磨好，为之后的加重渐进超负荷打好基础。"
- **22 赞反反方**："大重量只要能控制好向心离心做的标准，也可以很好的感受到念动合一。如果 up 说的大重量是控制不了的重量愣举……"
- **77 赞**："国内的健身圈最搞笑的是一群自然小白照着药罐子的方法练。"

**调和结论**：
- 轻重量的价值 = 打磨动作模式（认知期），不是找发力感
- 发力感在大重量（6-10RM）下自然会出现，不需要刻意在轻重量下找
- **81%RM 以上念动一致感受不到**——这和上一期意象训练调研的 EMG 研究一致

### 3.3 "独自训练不敢力竭"（BV1sL411S75p 评论，287 赞）

> "有人辅助敢冲最后一两下是最好的，我自己一个人练不敢完全力竭，进步很慢。"

**这是独自训练的硬伤**：
- 无法力竭 = 无法准确校准 RPE（你不知道自己到底还能做几个）
- 解法：用**减重量的力竭组**代替极限重量的力竭（比如用 70% 重量做到力竭，来感受"RPE 10 是什么感觉"）
- 或者用**停顿/离心控制**代替力竭来加难

### 3.4 "自然小白照着药罐子方法练"（BV1Qo4y1Z7jQ 评论，77 赞）

- 国内健身圈主流内容（包括 Jeff Nippard 翻译内容）很多是基于用药人群的研究
- 自然训练者的 RPE 校准、恢复速度、发力感强度都不同
- **含义**：不要把 Jeff Nippard 的 RPE 8 直接当你的 RPE 8——你的 RPE 8 可能和他的 RPE 6 是同一个生理状态
