## 一句话摘要

- **需求1（坐姿划船腰痛）**：刺痛是警示信号；核心结论=硬拉后接无支撑划船顺序不合理（先改顺序）→ 坐骨坐实/后倾 15-20°/拉向腹部（改姿势）→ 减重观察；长期用竖脊肌耐力（山羊挺身）+ McGill Big 3 + 臀肌强化。红旗症状出现即停训就医。
- **需求2（弯举阶梯过粗）**：+2.5kg 掉 6 次=哑铃 30%+ 跳档所致；解法按优先级=次数先行（double progression，不花钱）→ 自带 1.25kg 小片（20-30 元）→ 换 EZ杠/杠铃做主项 → 缆绳弯举/牧师凳/上斜哑铃做辅助。学术诚实标注：double progression 与 micro-loading 无 RCT 直接证据。
