# 底座习惯 · 记录口径与录入规范

> 建立日期：2026-10-20
> 适用期：**第 1–4 周底座期（2026-10-20 ~ 2026-11-16）**，只做底座、不做技巧。
> 数据位置：与晨脉同一个 InfluxDB 库（`training` bucket），measurement 前缀 `ppl_habit_*`。
> 本文是该组数据的**唯一口径来源**。口径有争议时以本文为准，不以聊天记录为准。

---

## 0. 一句话

这五项不是"养生清单"，是**给训练系统加一层恢复侧输入**——晨脉反映当天状态，底座习惯反映过去 7 天的恢复环境。两者合起来才能解释"为什么今天推不动"。

---

## 1. 存储位置（技术坐标）

| 项 | 值 |
|---|---|
| 库 / org | InfluxDB `training`，org `training-org` |
| measurement | `ppl_habit_sleep` / `ppl_habit_cardio` / `ppl_habit_alcohol` / `ppl_habit_smoke` / `ppl_habit_sitting` |
| 标签 | `session_id`、`source` |
| 时间戳 | 归属日 **20:00（UTC+8）**，默认记前一天 |
| 写入通道 | Node-RED `parse-training`（`/add-training`），与晨脉、做组共用一条管道 |
| 查询脚本 | `_verify/q_habit.py` |
| 录入脚本 | `_verify/enter_habit.py` |

**为什么是 5 个独立 measurement**：与 `ppl_morning_hr` 同构（一个指标一条曲线）。漏记某一项不会影响其他项，补录和画图都独立；如果塞进一个 measurement 的多字段，单位会混（小时/分钟/次/布尔），Grafana 每个字段还得单独拆查询。

---

## 2. 五个指标的定义

| # | 指标 | measurement.field | 单位 | 记法 | 目标 | 判定 |
|---|---|---|---|---|---|---|
| 1 | 睡眠时长 | `ppl_habit_sleep.hours` | 小时（7.5） | 每日 | 7~8 h | <7 标黄；连续 3 天 <7 视为底座未达标 |
| 2 | 有氧 | `ppl_habit_cardio.minutes` | 分钟（30） | 每次有氧 | 周合计 ≥150 min | 7 日 sum |
| 3 | 酒精 | `ppl_habit_alcohol.drinks` | 次（饮酒场合） | **事件式** | 周 ≤2 次 | 7 日内 `drinks>0` 的记录数 |
| 4 | 吸烟 | `ppl_habit_smoke.cigarettes` | 支 | **事件式** | 0 | 7 日 sum；无记录 = 0 |
| 5 | 久坐 | `ppl_habit_sitting.ok` | 0/1 | 每日 | 7 日 ≥5 天达标 | 自评：当天是否有意识每 60 分钟起身活动 2 分钟 |

**三项口径说明**：

- **睡眠只记时长**，不记起床时间。固定起床时间属于行为执行，靠日程而非数据验证；若以后需要验证，再加 `wake_time` 字段（新增字段不破坏历史点）。
- **酒精/吸烟是事件式**：发生了才写一条。没记录默认 0，但允许显式写 0（`酒0` / `没喝酒`），用于"今天确实没喝"的明确留痕。
- **久坐用达标制而非次数**：精确统计"每 60 分钟"做不到，硬记次数只会得到估数。**宁可粗一点，也不要假精度。**

## 3. 录入语法

一条消息写完全部，顺序无关，缺项自动跳过：

```
睡眠7.5 有氧30 酒0 烟0 久坐达标
睡眠7小时30分 有氧45 没喝酒 没抽烟 久坐未达标
```

| 关键词 | 可接受的写法 |
|---|---|
| 睡眠 | `睡眠7.5` / `睡眠7小时30分` / `睡了7h` |
| 有氧 | `有氧30` / `有氧30分钟` / `跑步40` / `单车30` / `椭圆机25` / `游泳30` / `跳绳15` |
| 酒精 | `酒1` / `喝酒2` / `酒0` / `没喝酒` |
| 吸烟 | `烟3` / `抽烟3` / `烟0` / `没抽烟` |
| 久坐 | `久坐达标` / `久坐未达标` / `久坐0` / `久坐1` |

### 时间归属规则

| 情况 | 记到哪天 |
|---|---|
| 默认（早上录） | **前一天 20:00** |
| 消息含「今天」 | 当天 20:00 |
| 脚本带 `--day 2026-10-18` | 指定日 20:00（补录用） |

```bash
cd D:/11.project/iwen-codex/codex-list/training-tracker-docker/_verify
python enter_habit.py "睡眠7.5 有氧30 酒0 烟0 久坐达标"
python enter_habit.py --day 2026-10-18 "睡眠7.5 久坐达标"   # 补录
python enter_habit.py --dry-run "睡眠7.5 有氧30"              # 只看不写
```

也可以直接在聊天里说，由我代为录入。

## 5. 与原始清单的 4 处口径修订

原始清单（第 1–4 周：只做底座）在落地时必须改这四处，否则数据会自相矛盾：

| 原文 | 问题 | 本文改为 |
|---|---|---|
| 有氧「每周 150 分钟（快走不算，要出汗）」 | ACSM 把快走（3–6 MET）算中等强度，"快走不算"是**个人口径**而非生理标准 | 保留"出汗"作为**你的**判定标准，但标明是个人口径，不是指南定义 |
| 睡眠「一周 5h 就掉 10–15% 睾酮」 | 结论方向对，但来自 **n=10 的小型实验室研究**，不宜写成定律 | 记为「一项小样本实验室研究」，见 §6 |
| 酒精「降到每周 ≤2 次」 | ≤2 不是安全阈值，只是风险分层的低档 | 保留目标，但注明不是"安全线" |
| 久坐「每 60 分钟起身 2 分钟」 | 无法精确计数，硬记会产生假数据 | 改为**达标制 0/1**，由自己判断 |

## 6. 证据注记（写清楚，避免以后自己怀疑）

- **睡眠与睾酮**：Leproult & Van Cauter, *JAMA* 2011，10 名年轻男性连续 1 周限睡 5 小时，白天睾酮下降 10–15%。方向可靠；样本小、周期短，效应量不宜外推到"少睡一晚就掉 10%"。
- **有氧 150 min/周**：WHO 2020 与 ACSM 的**下限**建议，不是最优值。证据主要指向心血管代谢健康，不是直接提升睾酮。
- **酒精**：对睾酮是剂量依赖的抑制，急性大剂量更明显；每周 ≤2 次是风险分层的低档，不是安全阈值。
- **吸烟**：唯一不设阈值的一条，剂量-反应无安全下限，"停"就是唯一定义。
- **久坐打断**：每 60 分钟起身的证据主要指向血糖与血管内皮功能，**不是睾酮**。这条的价值在代谢侧，别归因错。
